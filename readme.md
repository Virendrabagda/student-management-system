# Student Management System

## Introduction

Student Management System is a Python-based project used to manage student records.
It allows users to add, view, update, delete, and search student information.

## Features

- Add a new student
- View student records
- Update student information
- Delete a student
- Search for a student by ID
- Exit the application

## Technologies Used

- Python
- MySQL
- SQL

## Database

MySQL is used to store student information permanently.

Database Name:
`DB`

Table Name:
`STUDENTS`

## CRUD Operations

| Operation | SQL Command |
|---|---|
| Add Student | INSERT |
| View Student | SELECT |
| Update Student | UPDATE |
| Delete Student | DELETE |
| Search Student | SELECT + WHERE |

## Student Information

The system stores information such as:

- Student ID
- Student Name
- Course
- Marks

## How to Run

1. Install Python.
2. Install MySQL.
3. Create the required database.
4. Open the project in VS Code.
5. Run the Python file:

python main.py
